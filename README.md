# bankloan
📊 Power BI Dashboard: Bank Loan Report

📌 Overview

This Power BI dashboard provides a comprehensive analysis of bank loan data, helping financial analysts and decision-makers gain insights into loan applications, funded amounts, received payments, interest rates, and other key metrics. The dashboard includes various filters for in-depth analysis.

🚀 Features

Total Loan Applications, Funded Amounts, and Received Payments

Month-to-Date (MTD) and Previous Month-to-Date (PMTD) Comparisons

Good Loan vs. Bad Loan Analysis

Loan Status Breakdown

Loan Distribution by Month, State, Term, Employee Length, Purpose, and Home Ownership

Interactive Filters for Dynamic Insights

📊 Key Metrics

1️⃣ Loan Applications

Total Loan Applications

MTD & PMTD Loan Applications

2️⃣ Funded Amount

Total Funded Amount

MTD & PMTD Funded Amount

3️⃣ Amount Received

Total Amount Received

MTD & PMTD Total Amount Received

4️⃣ Loan Performance Analysis

Good Loan Percentage & Applications

Bad Loan Percentage & Applications

Funded Amount & Amount Received for Good and Bad Loans

5️⃣ Loan Status Overview

Breakdown of Loan Status with Total Funded Amount and Interest Rate

6️⃣ Loan Distribution Analysis

Loan Analysis by Month, State, Term, Employee Length, Purpose, and Home Ownership

Interactive filters to refine data visualization
